# Resources

## Use editorial monochrome storefront styling
Public storefront UI uses an editorial luxury system: #0A0A0A/#FFFFFF/#FAFAFA, Playfair Display headings, Inter UI text, hairline borders, square or subtly rounded geometry, generous whitespace, and restrained motion. Avoid neon/purple gradients, glassmorphism, large shadows, generic 3D/vector imagery, and excessive rounded cards.
